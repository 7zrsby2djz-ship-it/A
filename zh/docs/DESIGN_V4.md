# 明白 v4：美術、學習路線與對話節奏

2026-10-10。這次以現有明白為基礎，參考逐個單元完成的學習地圖；教材、緬文介面與使用者存檔沿用。

## 三個角色共同檢查的取捨

| 檢查角色 | 發現與考量 | 採用的調整 |
|---|---|---|
| 美術 | 大張卡片欠缺路線感；緬文較長，節點隨文字垂直置中會令連線錯位。 | 紙白與襯衫藍保留；圓形立體節點、緩彎連線、靠上的圖示與清楚狀態。窄螢幕縮小錯位幅度，深色與減少動態效果都有樣式。 |
| 語音 | 原播報少停頓，求助後接話與離開畫面後的延遲播報會互相干擾。 | 日常語音基準 0.88，依標點拆成語塊並留呼吸時間；保留個人語速、考試基準與真人錄音。取消語音後，過期事件不再啟動下一句。 |
| 流程檢查 | 略過曾計入完成，會讓地圖的進度失真；只有看過單字不能代表已練完。 | 略過另外記錄，完成才加進度。單字地圖依實際練習成績記錄，零分顯示為已練習而非精通；保留自由選課與補做入口。 |

地圖共用一個元件，分別呈現今天五步、六個對話情境內的段落，以及單字書的單元。每日路線隔天更新，對話與單字單元的累積進度保留。未完成的對話可接續原本位置。

角色採用既有原創飯糰 SVG。音效直接重用根目錄 `src/sfx.generated.js` 的 Kenney CC0 素材，沿用既有動態與按壓設計原則；沒有新增外部素材請求。成功、錯誤與完成音效維持較柔和音量，可獨立關閉，播放語音時避讓。
