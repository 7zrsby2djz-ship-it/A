# 按鈕與積木

個人用的 iPhone 學習網頁 App：
- **英文**：看懂 Claude／AI 工具介面上的英文（按鈕、權限、錯誤訊息），重點是相似字比較。
- **日文**：去日本自由行時能把一段對話走完。以聽懂日本人的自然回答為核心，搭配積木式句型。

使用者有心盲症（無法在腦中產生畫面）。**不要**設計「想像畫面」「記憶宮殿」這類記法；要靠文字、結構、拆解、對比、聲音、真實情境。

## 給接手的 AI（ChatGPT／Claude）

### 檔案結構
| 檔案 | 內容 |
|---|---|
| `index.html` | 組好的完整 App，可直接用瀏覽器打開。**不要直接改這個檔**，改 `src/` 後重新組。 |
| `build.sh` | 把 `src/` 組成 `index.html`（需要 Node.js 做語法檢查）。 |
| `src/head.html` | `<title>` 和全部 CSS。顏色都是變數，有淺色／深色兩套。 |
| `src/shell.html` | 頁面外框（主畫面、底部分頁列、練習用的全螢幕層）。 |
| `src/data_en.js` | 英文字庫 `EN_RAW`、易混字組 `GROUPS`、不收進練習的基本字 `STOP` / `NAMES`。 |
| `src/data_jp.js` | 日文積木 `B`、句型 `PAT`、開口練習情境 `SCENES`、助詞規則。 |
| `src/data_dlg.js` | 「把對話走完」的對話內容 `DLG`、每級預習單字 `DLG_W`。**擴充日文情境主要改這個檔。** |
| `src/app.js` | 主程式：狀態、存檔、複習排程、英文練習、各分頁畫面、事件處理。 |
| `src/dlg.js` | 對話練習：先聽不看字 → 理解題 → 拆解 → 選接話 → 第二輪 → 結果、分級解鎖。 |
| `src/words.js` | 日文單字卡（使用者按「不熟」的字）。 |
| `src/listen.js` | 耳機模式：自動連播練過的對話。 |

所有 `src/*.js` 會被組進同一個 `<script>`，彼此直接呼叫函式。

### 新增一個對話情境（例如餐廳）
在 `src/data_dlg.js` 的 `DLG` 陣列加一筆，照現有三個（`train`、`bus`、`way`）的格式：
- `me`：使用者先說的那句（`jp` 日文、`ro` 羅馬拼音、`zh` 中文）。
- `lv[1]`～`lv[5]`：5 個難度，依序為「簡單回答 → 自然一點 → 多一點資訊 → 快速口語 → 抓重點」。每一級都是完整的兩輪對話：
  - `r1` / `r2`：對方的回答。`ch` 是拆塊（[日文, 意思]），`q` 是理解題（`o` 第一個選項是正確答案，`k` 指向答案在哪一塊，`tag` 是題目類型），`easy` 是使用者說「ゆっくり」時對方改用的簡單說法（第 4、5 級才需要）。
  - `fu`：使用者怎麼接話，三選一，`ok: true` 只能有一個，每個都要有 `why`。
  - `end`：這段對話的結果。
- 在 `DLG_W` 加同一個 id，給每一級 3～6 個預習關鍵字。

### 存檔
- 進度存在瀏覽器 `localStorage`（key：`bnk-state-v1`）。
- 在 Claude 的 artifact 裡打開時，也會存到使用者的 Claude 帳號（雲端）。
- 存檔欄位定義在 `app.js` 的 `DEF()`。新增欄位時加在 `DEF()` 裡，舊存檔會自動補上。

### 已知限制
- 發音用手機內建的語音（Web Speech API），不是真人。
- 耳機模式要螢幕亮著才會一直播，iPhone 鎖螢幕就停。

### 目前的線上版本
在 Claude 的 artifact 上執行，網址由使用者保管。
