# 聽懂一句：獨立日文口語聽力

入口：`listening-jp/index.html`。完整單一 HTML，不需 API key、安裝套件或登入。

這是另做的學習工具。原本根目錄的英文／交通 App、`src/data_tasks.js`、`backup-v1` 全部保留；新工具不讀寫原 App 的 `bnk-state-v1`，也不把新教材排入交通課程。

## 學習目標與內容

使用者希望從完全聽不懂開始，理解日語成人影片的開場會話、一般口語與粗俗詞義。採取兩條分開的學習路徑：

1. **原創一般會話課程**：8 個單元、24 個小課、48 句。開場 → 自介 → 喜好／經驗 → 反應 → 否定／意願 → 請求 → 縮略 → 上下文。沒有成人場景、露骨對話或影片素材。
2. **詞義查詢**：36 個補充詞條，包括一般口語、粗俗稱呼、感受與 15 個成人語境詞義。成人內容只做中性字典解釋，標明多義、語體、使用場合，不組成情色情節。

這些是教材選詞，不是語料統計得到的頻率排行榜。合成聲音無法替代真人發音、口音、噪音或語用判斷；不能把課內答對宣稱為已能看懂影片。

## 每課的五步

1. 認識第一句（日文、振假名／拼音、中文、按需拆解）。
2. 認識第二句。
3. 第一題單句聽辨（三個中文選項，順序打散）。
4. 第二題單句聽辨。
5. A／B 兩句串聽，再辨認指定說話者的意思。

一次兩個新句子，約 2–4 分鐘；不倒數、不要求連勝、不硬性解鎖。看字與慢聽不處罰。第一次由第 1 課開始；之後優先接續中斷，再處理到期複習。

## 記錄與聲音

- 獨立 key：`kiku-independent-v1`。
- `text` 看字或答錯後學過；`support` 不看字，慢聽／重聽後三題都首次選對；`listen` 播放完成、無提示、無重播、三題首次選對。
- 純聽只是**當課已學句的辨認**，不是未見句遷移。第一次學習時先看兩句，不假稱盲測。
- 未成功播放、手動回報沒聲音、顯示文字，均不記成純聽。刷新或重新進入練習必須重新播放或用文字提示，不能僅靠殘留播放旗標解鎖答案。
- 課程結果只落帳一次。中斷課程保存目前步驟、題序和作答。
- 依完成方式排程：答錯 6 小時；看字或慢聽答對 1 天；連續純聽通過 1／3／7／14／30 天。
- Web Speech API，日文 `ja-JP`，以假名讀音供合成器朗讀。一般速度 0.70／0.85／1.00；慢速按鈕 0.60。頁面切到背景時停止播放。
- 支援查詞、收藏、搜尋、進度匯出與匯入。匯入前驗證內容並確認取代；不修改原 App。
- 未在真實 iPhone 驗證聲線及音訊啟動行為；螢幕鎖定播放不支援。

## 原始碼與建置

| 路徑 | 用途 |
|---|---|
| `src/data.js` | 句子、課程、詞條；漢字標 `{漢字\|かな}` |
| `src/app.js` | 獨立 UI、流程、語音、存檔、複習 |
| `src/style.css` | 手機／桌面、深色模式、減少動態 |
| `src/shell.html` | 頁面外框 |
| `validate.js` | 教材引用、唯一性、讀音、選項檢查 |
| `build.js` | 生成獨立 `index.html`，不改根目錄 |

```sh
node listening-jp/validate.js
node listening-jp/build.js
node tools/validate.js
./build.sh
```

新增課程時，每課維持兩個新句子，完整定義讀音、拼音、中譯、語體、拆解、兩個不同的干擾選項。改變課程總量時同步更新數量檢查與 UI。詞條的成人／一般分類不能被音訊循環自動混用。

## 本版驗證

- 原 App 的 `node tools/validate.js` 與 `./build.sh` 通過，原 `index.html` 產物相同。
- 新教材檢查、建置與 JavaScript 語法檢查通過。
- `node listening-jp/test-browser.cjs` 以 Playwright／Chromium 逐一走完 24 課；測試結果落帳不重複、重新整理接續、文字提示、慢速、重播、錯答、語音失敗、詞條分類／搜尋／收藏、備份匯出匯入、兩 App 存檔隔離。
- 測試用語音事件是模擬的，不能當成實際有聲證明。仍需在真實 iPhone 試聽。
- 手機 360／390、平板 768、桌面 1200 寬度檢查，另檢視手機深色模式。測試需要外部安裝 Playwright 和 Chromium；工具本身沒有這些依賴。
