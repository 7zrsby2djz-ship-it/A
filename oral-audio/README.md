# 鎖屏聽力音檔（oral-audio）

給「螢幕鎖住、口袋裡也能聽」用的**離線 MP3**。句子全部取自 App 已有的交通／生活對話（`src/data_tasks.js`、`src/data_life.js`），由選單 `batch01.selection.json` 指到教材節點，文字由來源自動組出，不手寫日文。

> 狀態：第一批 30 句已產生（合成語音），已接進 App：首頁「全部」→「鎖屏聽力」（`src/lockplay.js`），用 `<audio>` + Media Session 播放，60 個逐句 MP3 由 `tools/build-embed.cjs` 打包進單檔 `index.html`（約 +2.1 MB）。**未在 iPhone 實機試聽／測鎖屏**；鎖屏時自動接下一句是否被 iOS 允許，要實機確認（不行的話可改聽 `batch01_playlist.mp3` 單一檔）。

## 檔案

| 路徑 | 內容 |
|---|---|
| `batch01.selection.json` | 第一批選句（task/variant/node 或 chunk id） |
| `tools/build-batch.cjs` | 組句 → 讀音檢查 → Open JTalk 合成 → MP3 → `manifest.json` |
| `tools/setup-tts.sh` | 安裝 Open JTalk、下載並驗證 HTS 聲音 Mei |
| `batch01/mp3/NN_<id>.mp3` | 正常速度（1.0） |
| `batch01/mp3/NN_<id>_slow.mp3` | 慢速（0.8，Open JTalk `-r 0.8`） |
| `batch01/batch01_playlist.mp3` | 鎖屏連播：每句 正常 → 1.2 秒 → 慢速 → 1.5 秒 → 正常 → 2.5 秒，約 4 分 33 秒 |
| `batch01/manifest.json` | 每句 id、日文、振假名原文、假名、拼音、中文、說話者、來源節點、TTS 輸入、讀音模式、檔名、秒數、sha256 |
| `ATTRIBUTION.md` | 合成引擎與聲音授權 |
| `tools/build-embed.cjs` | 把逐句 MP3（核對 sha256）打包成 `generated/<batch>-audio.js`（`globalThis.ORAL_AUDIO`），`build.sh` 自動執行 |
| `generated/batch01-audio.js` | 產生檔，不要手改 |

不會覆蓋 `kana-rebuild/audio/`（44 個真人單音錄音）。

## 重新產生

```sh
sh oral-audio/tools/setup-tts.sh          # 第一次（需要 sudo、網路）
node oral-audio/tools/build-batch.cjs batch01
```

- 讀音檢查：先用漢字原文交給 Open JTalk（重音較自然），再把它推定的讀音和教材振假名的讀音比對；不一致時只把讀錯的那一段換成假名。第一批有 4 句被修正（`ttsReadingMode: "mixed"`）：
  - `金閣寺道` → きんかくじみち（Open JTalk 原本讀成 キンカクジドウ）
  - `40分`、`10分` → ぷん（Open JTalk 的讀音欄是 フン、發音欄其實已是 プン；換成假名只是讓比對一致，聲音不變）
  - `四つ目` → よつめ（原本 よっつめ）
- 加新批次：複製 `batch01.selection.json` 成 `batch02.selection.json`，改 `items`，執行 `build-batch.cjs batch02`。
- 之後若改用真人錄音：維持同樣的 `manifest.json` 欄位與檔名（`NN_<id>.mp3`），把 `synthetic` 改成 `false`、補上錄音者與授權即可。
